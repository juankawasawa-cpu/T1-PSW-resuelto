# Publicación del repositorio

1. Crea un repositorio vacío en GitHub y selecciona visibilidad Public.
2. En la terminal, dentro de la carpeta del proyecto, configura el remoto con la URL real de tu repositorio:

   `git remote add origin https://github.com/USUARIO/REPOSITORIO.git`

3. Publica la rama principal:

   `git branch -M main`

   `git push -u origin main`

4. Abre la pestaña Commits y confirma que se visualice el historial. No subas tokens, contraseñas ni archivos locales de configuración.
